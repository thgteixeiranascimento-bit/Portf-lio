Protocolo de integridade. Como este portfólio demonstra competência

Rigor antes de estética

Cada modelo publica seus checks de consistência (balanço fecha, caixa reconcilia, pontes somam) recalculados a cada mudança de premissa — erros não são ocultados.

Premissas explícitas

Todo resultado é apresentado como "valor estimado pelo modelo sob as premissas adotadas". Fato, premissa, estimativa e simulação são rotulados separadamente.

Orientação à decisão

Cada projeto responde explicitamente: qual decisão este modelo permite tomar? — investir, repactuar prazos, revisar orçamento, priorizar CAPEX.

Ferramentas e stack

Demonstrado neste portfólio: modelagem financeira interativa (JavaScript/SVG, arquitetura inputs → cálculos → outputs → checks), visualização de dados orientada a decisão, automação de coleta de dados públicos em Python (CVM — Dados Abertos) e documentação/versionamento em Git.

Em desenvolvimento — ainda não incluído nesta versão: versões dos modelos em Excel/VBA (Power Query, Power Pivot) e dashboards em Power BI (modelagem dimensional + DAX). Serão adicionados ao repositório com a mesma governança.
