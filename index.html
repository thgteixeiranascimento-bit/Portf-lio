03 / Método

Como este portfólio demonstra competência.

Rigor antes de estética

Cada modelo publica seus checks de consistência (balanço fecha, caixa reconcilia, pontes somam) recalculados a cada mudança de premissa — erros não são ocultados.

Premissas explícitas

Todo resultado é apresentado como "valor estimado pelo modelo sob as premissas adotadas". Fato, premissa, estimativa e simulação são rotulados separadamente.

Orientação à decisão

Cada projeto responde explicitamente: qual decisão este modelo permite tomar? — investir, repactuar prazos, revisar orçamento, priorizar CAPEX.
